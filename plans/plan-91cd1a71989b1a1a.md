# Offline SVG charts for ExpenseTracker summary

Add zero-dependency, theme-aware SVG charts (monthly bar chart + category donut) to the ExpenseTracker summary card in C:\utilities\utilities, with a shared per-currency toggle so EUR/GBP/USD/BGN are never mixed.

## Summary

`src/pages/ExpenseTracker.tsx` in **Utility Hub** (`C:\utilities\utilities`) gains two hand-rolled SVG charts inside the existing right-hand summary card: a monthly spending bar chart and a category donut chart. Both are driven by a shared currency toggle and reuse the existing `totalsByMonth` / `totalsByCategory` / `fmtMoney` helpers. No new dependencies — pure SVG markup, Cyrillic-safe via native `<title>` tooltips and HTML legend text.

## Implementation Steps

### 1. New file: `src/pages/expenses/ExpenseCharts.tsx`

Follows the established multi-part-tool pattern (`src/pages/pdf/`, `src/pages/excel/`). Exports page-local chart components (not promoted to `src/components/` since they're expense-specific).

**`CurrencyToggle`** — segmented button row over `CURRENCIES` (`EUR GBP USD BGN`), styled like the existing `bg-sky-500/10` chips. Buttons for currencies with no entries render `disabled:opacity-40`. Selected state uses `bg-sky-500 text-white`.

**`MonthlyBarChart`** — props: `data: { month: string; total: number }[]`, `currency: CurrencyCode`.
- SVG `viewBox="0 0 320 150"` with `className="w-full h-auto"` for responsiveness.
- 3 horizontal gridlines + y ticks computed from a "nice" max (round up to 1/2/5×10ⁿ); tick labels via `Intl.NumberFormat(LOCALE, { notation: 'compact' })`.
- Bars: `<rect className="fill-sky-500 hover:fill-sky-400 dark:fill-sky-400 dark:hover:fill-sky-300">` with `<title>{month}: {fmtMoney(total, currency)}</title>` for the native tooltip.
- X labels: `Intl.DateTimeFormat(LOCALE, { month: 'short' })` on `new Date(month + '-01')`, plus 2-digit year when data spans >12 months. Text: `text-[9px] fill-slate-500 dark:fill-slate-400`.
- Single-month edge case renders fine; months sorted ascending (reverse of `totalsByMonth`'s descending order).

**`CategoryDonut`** — props: `data: { label: string; total: number }[]`, `currency: CurrencyCode`.
- SVG `viewBox="0 0 120 120"`, r=40, stroke-width 22 arc `<path>`s (polar→cartesian helper, `large-arc` flag).
- Fixed slice palette staying in the slate/sky family: `['#0ea5e9','#38bdf8','#0284c7','#0369a1','#7dd3fc','#818cf8','#a5b4fc','#94a3b8']` — readable in both light and dark modes.
- Center `<text>` = total `fmtMoney(sum, currency)`.
- Each slice gets `<title>{label}: {fmtMoney(total, currency)} ({pct}%)</title>` — UTF-8/Cyrillic-safe native tooltip.
- HTML legend below the SVG (not SVG text — better wrapping for long Cyrillic custom categories): color swatch + category name + `fmtMoney` + pct, in `text-xs`, swatch via inline `style={{ background }}`.

## Design decisions

- **Bar** (not line) for the trend — simpler, touch-friendly, reads better at small widths.
- **Native `<title>` tooltips** — zero code, accessible, and natively UTF-8 (covers the Cyrillic requirement); legend carries exact values so no JS tooltip positioning is needed.
- **One shared currency toggle** for both charts — a single axis/palette is never mixing currencies, matching the app's "no fake exchange rates" rule.
- Explicit hex slice palette is intentional: Tailwind `dark:` can't restyle computed SVG geometry colors cleanly, and the chosen sky/indigo/slate hexes work on both `bg-white` and `bg-slate-900` cards.

## Risks/Considerations

- Replacing the text month/category readouts loses raw-text scanning but the legend + tooltips preserve every number — flagged here in case you'd rather keep both.
- `verbatimModuleSyntax` requires `import type` for `CurrencyCode` in the new file; `noUnusedLocals` is enforced — accounted for.
- Entries with malformed `date` strings (< 7 chars) could produce odd `month` keys; `date.slice(0,7)` is already trusted by existing code, so no new validation is added.
