# Text & Quick Utility Suite — TextTools + CalcTools

Add two lazy-loaded, 100% client-side modules — a text/string workbench and a timezone + percentage/VAT calculator — wired into routes, nav, and Home cards, then build and deploy.

## Summary

Two new utility pages following the established module pattern (lazy route + sidebar nav item + Home card + dark/light classes). Both zero-dependency beyond what's installed; currency/number output goes through `src/utils/locale.ts`; user-facing strings wrapped in `t()` for i18n consistency.

## Implementation Steps

1. **`src/pages/TextTools.tsx`** (~150 lines)
   - Single textarea input; live stats bar under it: words, characters (with/without spaces), lines, sentences, estimated reading time (`words / 200 wpm`, `fmtNumber` for counts).
   - Case converter buttons: UPPERCASE, lowercase, Title Case, camelCase, kebab-case, snake_case, slugify (lowercase, strip diacritics via `normalize('NFD')` + non-alnum → `-`).
   - Line ops buttons: sort A→Z (`Intl.Collator` for locale-aware sort), reverse order, dedupe unique, remove blank lines, trim each line.
   - Lorem Ipsum generator: paragraph count input (1–10) + Generate → writes classic Lorem into the textarea.
   - Copy output button (clipboard + Copied! feedback) and ShareButton (text payload) for consistency.
   - Strings wrapped in `t()` so dictionary entries can be added later (keys fall back to English — fine to ship without translating every internal string).

2. **`src/pages/CalcTools.tsx`** (~140 lines) — segmented tabs (same pattern as PdfTools/ExcelTools):
   - Tab 1 **Time zone converter**: local datetime input + "from" zone (default `Intl.DateTimeFormat().resolvedOptions().timeZone`) + "to" zone select (curated ~30 common `Intl`-supported zones incl. Sofia/Dublin/Amsterdam), live formatted result via `fmtDateTime` + a "now in both zones" quick card.
   - Tab 2 **Percentage & VAT**: three quick calculators — X% of Y, percent change (a→b), and VAT add/remove with configurable rate (default 20%) — all results via `fmtNumber`, VAT totals via `fmtMoney` (uses existing `CURRENCY` detection).

3. **Wiring**
   - `App.tsx`: two lazy imports + routes `/text-tools` and `/calc-tools`.
   - `Layout.tsx`: nav items — `Text Tools` (`Type` icon), `Calc & Time` (`Calculator` icon).
   - `Home.tsx`: two `ToolCard`s — "Text Workbench" and "Calc & Time Converter" (English strings wrapped in `t()`).
   - i18n dict entries for nav labels + card strings can be added to `src/utils/i18n.ts` (bg/es/fr/de/nl) — include them since the dict pattern is established.

4. **Docs**: `HANDOVER.md` status line → "seventeen tools" + locale/i18n note updated.
