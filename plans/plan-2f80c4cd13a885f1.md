# Utility Hub — Restore Legacy Expenses Model + Currency Preference

Port the financialAnalyst receipt model into ExpenseTracker.tsx (VAT, entity, notes, per-entry currency, edit, monthly/category summaries) and add an app-wide currency preference (`utility-hub.currency`, EUR/GBP/USD/BGN) independent of UI locale.

## Summary

Two linked features from the Cascade prompt: (1) restore the legacy financialAnalyst expense/receipt data model into the existing `/expenses` page — VAT breakdown, entity, notes, per-entry currency, edit-in-place, per-currency + monthly + category summaries; (2) an app-wide currency preference (`utility-hub.currency`, default region-mapped else EUR) with a header/sidebar selector, formatting independent of language. Offline rule → no live FX API; totals stay grouped per currency.

## Data model (Entry v1-compatible — old entries migrate via optional fields)

```ts
interface Entry {
  id: string; vendor: string; date: string            // YYYY-MM-DD
  amount: number                                      // total incl. VAT
  currency: CurrencyCode                              // default = pref at entry time
  category: string                                    // merged set or free text
  notes?: string; entity?: string; vatRate?: number   // % incl.
  source?: string                                     // receipt filename
}
```

`vatAmount` derived (`amount − amount/(1+rate/100)`), not stored. Old `utility-hub.expenses.v1` rows: missing `currency` defaults to the **region-derived** currency (exact old behavior), other fields absent = optional.

Merged categories: Meals, Travel, Supplies, Software, Office, Fuel, Maintenance, Cleaning Supplies, Utilities, Other + **"Custom…"** → free-text input (Cyrillic-safe: Домакинство, хляб).

## Implementation

### 1. `src/utils/locale.ts` — currency preference system
- `CURRENCIES = ['EUR','GBP','USD','BGN']`, `CURRENCY_KEY = 'utility-hub.currency'`
- `getCurrency()`: pref if valid → else `REGION_CURRENCY[REGION]` if in list → else `'EUR'`
- `setCurrency(c)` → writes key + dispatches `window` event `utility-hub:currency`
- `useCurrency(): [code, set]` — subscribes to the event + `storage` (cross-tab)
- `fmtMoney(n, currency = getCurrency())` — `Intl.NumberFormat` per-currency `Map` cache (replaces the frozen module-level formatter)
- **Remove** static `export const CURRENCY` → fix 2 consumers: `CalcTools.tsx` (label) and `ExpenseTracker.tsx` both switch to `useCurrency()`

### 2. `src/components/CurrencySelect.tsx` (new)
Compact `<select>` of the 4 codes, styled like the sidebar/footer chips, `aria-label={t('Currency')}`.

### 3. `src/components/Layout.tsx`
Mount `<CurrencySelect />` beside `ThemeToggle` in the mobile header and in the sidebar bottom row (with InstallButton). No language selector exists today — this is the first global preference control.

### 4. `src/pages/ExpenseTracker.tsx` — rewrite
- Form: vendor, date, amount + **currency select** (defaults to pref), category select + Custom… free text, entity, notes, optional VAT rate %
- **Edit-in-place:** pencil loads entry into form → "Save changes" / cancel (legacy review workflow parity)
- List rows: vendor, date, category, entity chip, amount in entry currency, VAT badge, notes line
- **Summary block:** per-currency total chips; monthly table (YYYY-MM → per-currency totals + running average); per-category subtotals
- Excel export columns: Vendor, Date, Amount, Currency, Category, Entity, VAT rate, VAT amount, Notes, Source + a **Summary sheet** (category + monthly totals per currency). Keep ShareButton.

### 5. `src/utils/i18n.ts` + `HANDOVER.md`
Add `'Currency'` ×5 locales. Doc: restored model fields, `utility-hub.currency` key (prefix ⇒ auto-included in backups), per-currency-totals FX decision.
